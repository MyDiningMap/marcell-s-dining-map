    Belépés szerkesztéshez

    Szerkeszteni csak a lista tulajdonosa tud. Add meg a GitHub-tokenedet, ami írni tudja a marcell-dining-map repót. A token csak ebben a böngészőben marad, sehova máshova nem kerül.

    Hogyan kapok tokent?
    1. Nyisd meg: github.com → Fine-grained token
    2. Token name: pl. „marcell-dining-map”, Expiration: amennyi tetszik (pl. 1 év).
    3. Repository access: „Only select repositories” → válaszd ki a marcell-dining-map repót.
    4. Permissions: kattints az „+ Add permissions” gombra, válaszd a Contents sort, majd mellette a „Read-only” legördülőt állítsd „Read and write”-ra.
    5. Generate token, majd másold be ide.

    Egyszerűbb alternatíva: classic token, amin csak a public_repo legyen bepipálva.
